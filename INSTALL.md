# Jazz Jackrabbit — installation

Requires Retro-Go SD **v2.0.0-rc1 or later** on the Game & Watch.

1. Open the project's browser packer Page and select your Jazz Jackrabbit
   game-data folder. The converter runs locally in your browser; files are
   not uploaded. Download the generated SD-card ZIP.

2. Extract the ZIP to the root of the SD card. It contains `Jazz.bin` and
   the generated `Jazz.jj` pack side by side under `/homebrews/`.

3. Start "Jazz Jackrabbit" from the Homebrew tab. The first start copies the
   pack to the external flash: it takes a few minutes.

The game data is not included: you need Jazz Jackrabbit 1 for DOS (full game,
shareware episode or Holiday Hare). The browser packer lists the files it
needs and verifies them locally.

Controls: D-pad = move (up = look up, down = crouch), A = jump (validate in
the menus), B = fire, TIME = change weapon, GAME = game menu / back,
PAUSE/SET = Retro-Go menu (savestates; Options: music, sound, swap A/B).
A savestate restarts its level from the last checkpoint reached, with the
score, lives and ammo of the moment.

# Jazz Jackrabbit — installation (français)

Nécessite Retro-Go SD **v2.0.0-rc1 ou plus récent** sur la Game & Watch.

1. Ouvrir la page de préparation du jeu et sélectionner le dossier des
   données Jazz Jackrabbit. Le convertisseur fonctionne localement dans le
   navigateur : aucun fichier n'est envoyé. Télécharger le ZIP pour la carte
   SD.

2. Extraire le ZIP à la racine de la carte SD. Il contient `Jazz.bin` et le
   pack `Jazz.jj` généré, côte à côte dans `/homebrews/`.

3. Lancer « Jazz Jackrabbit » depuis l'onglet Homebrew. Au premier
   lancement, le pack est copié dans la flash externe : cela prend quelques
   minutes.

Les données du jeu ne sont pas fournies : il faut Jazz Jackrabbit 1 pour
DOS (jeu complet, épisode shareware ou Holiday Hare). La page indique les
fichiers nécessaires et les vérifie localement.

Commandes : croix = déplacements (haut = regarder en haut, bas =
s'accroupir), A = sauter (valider dans les menus), B = tirer, TIME = changer
d'arme, GAME = menu du jeu / retour, PAUSE/SET = menu Retro-Go (sauvegardes ;
Options : musique, son, inverser A/B). Une sauvegarde reprend son niveau au
dernier point de passage atteint, avec le score, les vies et les munitions
du moment.
