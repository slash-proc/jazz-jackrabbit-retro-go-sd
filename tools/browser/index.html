Jazz Jackrabbit · Game & Watch Retro-Go SD

Prepare your game files

Choose the folder containing your DOS Jazz Jackrabbit files. This page converts them locally in your browser; your game files are never uploaded.

Create the pack

  1. Choose the folder containing files such as PANEL.000, LEVEL0.000 and SPRITES.000.
  2. Wait while the browser prepares pictures and music. Keep this tab open.
  3. Download the ZIP and install it to a Retro-Go profile with gwprov project install.

Ready. Nothing is sent to a server.

What the ZIP contains

      
homebrews/Jazz.bin and homebrews/Jazz.jj. The game data pack is made from the folder you choose; the homebrew binary is included with this page.

      
The converter runs as a sandboxed WASM module with no imports. No files are sent to any server.
